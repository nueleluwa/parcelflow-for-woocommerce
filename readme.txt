Live ParcelFlow shipping rates, carrier selection, shipment booking and tracking for WooCommerce.

== Description ==

* Live ParcelFlow carrier rates at WooCommerce checkout (a standard shipping method for shipping zones).
* Product HS tariff code, declared value and customs description fields.
* Shipment booking after payment: manual administrator approval by default, optional automatic mode.
* Duplicate-booking protection and reconciliation of uncertain booking outcomes.
* Shipment dashboard, logs, CSV export and API status page (ParcelFlow menu).
* Customer shipment information in My Account and a /track-shipment/ tracking page.

Status: pre-release (0.1.0). Not production-ready until the open API questions in docs/API-QUESTIONS.md are answered.
